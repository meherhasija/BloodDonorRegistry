# Blood Donor Registry System

A collection of five Full Stack Development projects demonstrating the evolution of a Blood Donor Registry System using modern web technologies. The projects cover frontend development, REST API integration, React.js, Node.js, Express.js, authentication, and MongoDB database connectivity.

## Projects Included

### 1. Blood Donor Registry – Fetch API & JSON Server
**Technologies:** HTML5, CSS3, JavaScript, Fetch API, JSON Server

- Developed a responsive donor registration interface.
- Implemented CRUD operations using REST API requests.
- Added form validation, search, and filtering.
- Used JSON Server as a mock backend.

### 2. Blood Donor Management Dashboard – React.js
**Technologies:** React.js, JSX, JavaScript, CSS3, React Router

- Built a single-page donor management application.
- Implemented reusable React components and routing.
- Added donor registration, editing, deletion, and filtering.
- Used React Hooks and localStorage for state management and data persistence.

### 3. Donor Management REST API – Core Node.js
**Technologies:** Node.js, HTTP, File System, Events, JSON

- Created a REST API using built-in Node.js modules.
- Implemented CRUD operations and request handling.
- Used JSON files for data storage.
- Implemented EventEmitter for donor-related event notifications.

### 4. Secure Donor REST API – Express.js & JWT Authentication
**Technologies:** Node.js, Express.js, JWT, bcrypt, dotenv

- Developed RESTful API endpoints using Express.js.
- Implemented donor management with CRUD operations.
- Added user registration and login functionality.
- Used bcrypt for password hashing and JWT for authentication.
- Implemented middleware for validation, logging, and error handling.

### 5. Blood Donor Registry – MERN Stack Application
**Technologies:** MongoDB, Express.js, React.js, Node.js, Mongoose, Vite

- Developed a full-stack donor management application.
- Integrated a React frontend with an Express backend.
- Used MongoDB Atlas for cloud database storage.
- Implemented donor registration, updates, deletion, and filtering.
- Added dashboard statistics and REST API integration.

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript, React.js
- **Backend:** Node.js, Express.js
- **Database:** JSON, localStorage, MongoDB Atlas
- **API Development:** REST APIs, Fetch API
- **Authentication:** JSON Web Tokens (JWT), bcrypt
- **Tools:** VS Code, npm, Postman, Git, GitHub

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/meherhasija/BloodDonorRegistry.git
   ```

2. Open the required program folder.

3. Install dependencies where required:

   ```bash
   npm install
   ```

4. Follow the individual README file inside each program for setup and execution instructions.
